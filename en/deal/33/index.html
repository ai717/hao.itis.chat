GitHub Codespaces: 120 Free Core Hours of Cloud Dev Environment per Month

Personal free accounts include 120 core hours + 15 GB storage per month (about 60 hours on a 2-core machine) — a ready-to-use cloud dev environment in the browser or VS Code

How to claim

  1. Open any GitHub repo and click Code → Codespaces

Eligibility：GitHub personal accounts (organization accounts get no free quota)

Region：Available worldwide

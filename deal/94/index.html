GitHub Copilot 学生免费版

认证学生免费使用 Copilot，代码补全不限次数（普通免费版每月 2000 次）

AI/软件/会员 · 全球可用 · 截止：长期/未注明截止

领取步骤

  1. 访问 GitHub Education 完成学生认证
  2. 在 GitHub 设置中启用 Copilot Student
  3. 在 IDE 中登录 GitHub 账号使用 Copilot

门槛：通过 GitHub Education 认证的学生

地区：全球可用

风险提示：GitHub 每月复核学生资格，失去学生身份后权益收回；无明确结束日期

出处原文

Copilot Student is free for students verified through GitHub Education, and GitHub lists no end date, though it re-checks eligibility every month.

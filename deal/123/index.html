领取步骤

  1. 安装 DeepSeek Harness（dsh）
  2. 在 dsh 中安装官方插件：dsh plugin --profile web add @ebony-vinyl/dsh-our-free-model（带 scope 的官方包，勿装无 scope 同名包），或按仓库 README 使用 Release 安装包
